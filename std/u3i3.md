# STD-U3I3 — three-phase meter

*Member of the [rbAmp STD family](overview.md); everything on the
[family page](overview.md) applies.*

## What it is

A three-phase energy meter module: **three voltage and three current inputs** with synchronous sampling,
the full STD feature set, and a choice of I²C or Modbus RTU. Variant code `0x63`.

It works as a sub-meter / smart-meter front end for a master (ESP32, Arduino, Raspberry Pi, PLC), or
directly on a Modbus RTU network (through an external RS-485 transceiver) as a meter, including a float32 register profile of 13 values for inverters and
monitoring systems ([Modbus transport](reference/12_transport_modbus.md)).

The module ships **with a current sensor for every channel**: each channel is calibrated together with its
sensor from the kit, and every sensor is labelled with its channel. The kit includes a current sensor
in one of two ratings: 60 A or 100 A.

---

## Voltage connection

The voltage terminal block has four positions: **N, L1, L2, L3**. The module measures phase-to-neutral
voltages, so the neutral must be connected. Wire and fuse rule: [Hardware](hardware.md#voltage-connection).

---

## Three-phase features

- Per-phase U / I / P / Q / S / PF plus grand and per-phase totals, all from one coherent measurement
  window.
- Signed import/export energy by the phase balance (the standard meter convention) — correct totals on
  sites that export on one phase while importing on another.
- Phase angle of each voltage input and the phase sequence (forward / reverse / abnormal) — check the
  wiring before trusting per-phase readings.
- Eight independent snapshot banks.
- Hourly history: the last 7 hourly records (energy per phase and an electrical summary) kept on the module; records are written once the master has set the time, and a part-hour record is flagged. See [Energy and periods](energy-periods.md).
- Sampling about 3 kHz per channel, windows of whole mains cycles.

## Measured characteristics

Measured on one production module per kit (60 A and 100 A), each channel individually calibrated together with its sensor, against a reference meter on a resistive load. Current is given as the primary current with one pass of the wire through the sensor; on STD-U3I3 the figures cover all three channels.

| Parameter | 60 A kit | 100 A kit |
|---|---|---|
| Current error | ±0.2 % in range 0.005 A – 75 A | ±0.2 % in range 0.005 A – 100 A |
| Upper end of the range | 75 A | 129 A |
| Voltage error | ±0.2 % | ±0.2 % |
| Power factor, resistive load | 0.999–1.000 | 0.999–1.000 |
| Reads from | 4.8 mA | 4.8 mA |
| Noise with no current | 0.2 mA | 0.35 mA |

## Typical uses

- The main meter of a three-phase home, a building, a production floor or a workshop.
- Three-phase sub-metering: a feeder, a workshop, an EV charger.
- Solar self-consumption: separate import and export energy, the float32 profile points for a Modbus master.
- Feeder monitoring in a distribution cabinet.
